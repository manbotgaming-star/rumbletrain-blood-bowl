Rumble Train Blood Bowl Team Builder V4.8

PRINT LAYOUT IMPROVEMENTS
-------------------------
Page 1 — Team Roster
- Added larger summary boxes for Players, Team Cost and Treasury.
- Replaced the tiny sideline text with a prominent Team Extras section.
- Team Extras now has five large boxes:
    Team Re-rolls
    Apothecary
    Assistant Coaches
    Cheerleaders
    Dedicated Fans
- Re-roll box also shows cost per re-roll and total re-roll spend.

Page 2 — Skills & Traits Reference
- Larger overall text.
- Larger row padding and explanations for easier table-side reading.
- Skill/Trait names are more prominent.

DISPLAY FONT
------------
Print headings now use the open-source Google font "Graduate", with
Impact/Arial Black fallbacks. It gives a collegiate/sports-block feel
similar in spirit to Blood Bowl branding without copying the exact logo font.

The print routine waits for the display font to load before opening Print.

UPDATE GITHUB
-------------
1. Unzip this package.
2. Replace team-builder.js in the GitHub repository.
3. Commit to main.
4. Wait for GitHub Pages to redeploy.
