Rumble Train Blood Bowl Team Builder V5.17

LEAGUE IMPORT READY SAVE FORMAT
-------------------------------
Updated the Team Creator save format so saved roster files now include a
league-import snapshot for every player.

Each saved player now includes:

uid
positionId
name
number
position
ma
st
ag
pa
av
skills
primary
secondary
cost

This gives the League Commissioner import process enough information to
validate the submitted roster against the League workbook's BasePositions data.

IMPORTANT:
Permanent League Player IDs are NOT saved by the Team Creator.
They will be generated by the League workbook when the Commissioner imports
the submitted roster.

Example future League Player IDs:

CAR-S01-001
CAR-S01-002
CAR-S01-003

The format means:

CAR = Team ID
S01 = Season in which the player joined
001 = sequential player number generated by the League workbook


SAVE FILE METADATA
------------------
The saved team file now uses:

version: 5.17
schemaVersion: 2

It also includes:

teamCost
treasuryRemaining
playerCount

These values are intended to help the Commissioner validate a submitted roster.


BACKWARD COMPATIBILITY
----------------------
Loading saved team files is unchanged.

The Team Creator still rebuilds a loaded roster from the existing positionId
and player name information, so the additional saved fields do not interfere
with normal Load Team File behaviour.

Older saved roster files can still be loaded by the Team Creator.


PRIMARY / SECONDARY SKILL ACCESS
--------------------------------
Primary and Secondary skill access remains included for all supported rosters.

The Choose Players table includes:

Primary | Secondary

The printout continues to include the Position Advancement Reference on page 2.

UPDATE
------
1. Replace the existing team-builder.js file in GitHub with
   team-builder-v5.17.js.

2. Rename it to team-builder.js if your GitHub repository currently uses that
   filename.

3. Commit the change to main.

4. Wait for GitHub Pages to deploy.

5. Change the GoDaddy loader from ?v=5.16 to ?v=5.17.
